What to include

  • Bug reports: the converter you used, the browser and OS, and any error message that appeared. If you can, share a small sample file (or the smallest file that reproduces the issue).
  • Feature requests: the formats you want to convert, what you'd use it for, and whether you've tried an alternative.
  • Privacy questions: check the Privacy Policy first. If the answer isn't in there, send us a note.
  • DMCA / takedown notices: we don't host user content, but if you believe content displayed on the Service infringes your rights, email the address above with the standard DMCA elements.

Response time

This is a small, independently-run site. We aim to reply within a week. Spam and unsolicited sales pitches are filtered.
