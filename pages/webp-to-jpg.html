About WEBP and JPG

Need to send a photo, post it online, or open it in an app that doesn't accept WEBP? Converting to JPG takes one click here. Multiple files are returned as a single ZIP.

What this converter does

  • Decodes your WEBP files using your browser's built-in image engine.
  • Re-encodes each image as JPG.
  • For a single file, you get the converted image directly. For multiple files, you get a ZIP.

Is the conversion lossy?

JPG is a lossy format. Choose a quality preset above to balance file size and image fidelity. "Standard" works well for photos; "High" is best when you'll edit further; "Compact" minimizes file size for web sharing.

Privacy

Conversion happens entirely in your browser. Nothing is uploaded. You can verify by disconnecting from the internet after the page loads — this page will still convert.
