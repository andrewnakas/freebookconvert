How it works

This tool uses Tesseract.js (a WebAssembly build of Google's open-source Tesseract OCR engine) and pdf.js (the PDF engine built into Firefox) to render each page of your PDF and recognize the text on it. Everything runs locally — the PDF never leaves your device.

Plain text vs. searchable PDF

  • Plain text (.txt): just the recognized text, one block per page. Smallest output. Use this when you want to paste into a document or feed text into another tool.
  • Searchable PDF (.pdf): the original page images with an invisible text layer behind them. Looks identical to the source PDF, but you can highlight, copy, and Ctrl-F. Larger file size because the page images are embedded.

How long does it take?

OCR is computationally expensive. On a modern laptop, expect about 3–10 seconds per page; on a phone, 20–40 seconds per page. A 50-page scanned book takes a few minutes either way. The first run also downloads the English language model (~4 MB) and the OCR engine (~10 MB); these are cached after that.

Accuracy tips

  • Clean, high-contrast scans get near-perfect results. Faint or skewed scans are noticeably worse.
  • The 3x render scale option helps with small text but takes about twice as long as 2x.
  • Handwriting is not supported — this is printed-text OCR only.

Privacy

The PDF stays in your browser. The only network requests after the page loads are for the OCR engine itself and the English language data, both fetched once and cached. You can verify by opening DevTools → Network before running a conversion.
