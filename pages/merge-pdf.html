What merging actually does to the file

This is not a re-print. The tool copies the page objects out of each source document and writes them into a new one, so the text stays selectable, links keep working, and vector artwork stays sharp at any zoom. A scanned page comes out exactly as sharp as it went in, and a text page does not turn into a picture of text. Nothing is re-compressed, which is why the merged file is usually close to the sum of the inputs.

Order is the order you add them

Pages appear in the sequence the files were added, and every page of file one lands before the first page of file two. If you drop them in the wrong order, hit the × next to a file to remove it and add it again at the end. There is no page-level reshuffling here — this tool concatenates whole documents.

Typical reasons people merge

  • A signed contract that came back in pieces. Signature page from one place, the agreement from another.
  • Scans from a flatbed. Many scanners emit one PDF per page. Merging turns 14 files into one document.
  • Expense or tax submissions. Receipts, statements, and a summary sheet as a single attachment.
  • Coursework and applications. Portals that accept exactly one file.
  • Chapters written separately. Stitch drafts together before sending for review.

Why doing this in the browser matters here

Merging is the conversion people are most likely to run on genuinely sensitive documents: leases, payslips, passports, discharge summaries. Every upload-based merger asks you to hand those to a server and then trust a retention policy. This one has no server to hand them to. Load the page, turn off your Wi-Fi, and the merge still completes — that is the difference, and you can verify it in about ten seconds.

Limits worth knowing

  • Password-protected PDFs will not open. Remove the password in your PDF reader first, then merge.
  • Very large batches use memory. Every document is held in RAM while merging. On a phone, keep the total under roughly 100 MB.
  • Mixed page sizes stay mixed. An A4 page and a Letter page keep their own dimensions. Most printers shrink-to-fit without a visible difference.
  • Form fields can collide. If two source PDFs use the same field names, the merged form may behave oddly. Flatten the forms first if that matters.

Questions people actually ask

Are my PDFs uploaded anywhere?

No. The merge runs inside this browser tab using WebAssembly. Open DevTools, watch the Network tab during a merge, and you will see no request carrying your file. Turning off Wi-Fi after the page loads also works as a test.

How many PDFs can I merge at once?

There is no fixed limit. The practical ceiling is your device's memory, since every document is loaded at once. A laptop handles a few hundred megabytes comfortably; a phone starts struggling well before that.

Can I reorder the pages inside the merged file?

Not page by page. Documents are joined whole, in the order you added them. Remove a file with the x button and add it again to move it to the end.

Does merging reduce quality?

No. Pages are copied across rather than re-rendered, so text stays selectable and images are not re-compressed. The merged file is roughly the combined size of the originals.

Why does it fail on one of my files?

The usual cause is password protection or encryption. Open that PDF in your reader, save an unprotected copy, and merge that instead. A corrupted or partially downloaded PDF will also fail to load.

Can I merge images and PDFs together?

Not in one step here. Convert the images to a PDF first with Images to PDF, then merge the two PDFs.
